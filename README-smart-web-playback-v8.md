# Smart Web Playback Protection V8

هذه النسخة مبنية مباشرة على النسخة الحالية المرفوعة، مع الحفاظ على الوظائف الموجودة وعدم حذف محركات API/Native/WebView/Player Intelligence.

## ما أضيف

- شاشة تجهيز سوداء أثناء تشغيل مصدر Web؛ صفحة الموقع لا تظهر للمستخدم أثناء مرحلة الاكتشاف.
- مهلة تشغيل Web إجمالية ثابتة 20 ثانية للجلسة، وليست 20 ثانية جديدة لكل fallback.
- عند ثبوت التشغيل قبل المهلة يظهر الفيديو فوراً.
- إذا انتهت المهلة ولم يوجد تشغيل فعلي، تظهر رسالة فشل واضحة.
- WebView يبقى mounted في الخلفية أثناء التجهيز حتى يستمر JavaScript والـplayer lifecycle.
- Player Focus بعد إثبات التشغيل: إخفاء محتوى الصفحة بصرياً وإبقاء منطقة المشغل ومكوناته مرئية، بدون حذف عناصر DOM أو إزالة الصفحة من الذاكرة.
- حماية أقوى من `window.open` وtarget=_blank وروابط/مسارات popup/popunder/interstitial والإعلانات الواضحة.
- Smart Interaction ما زال مقيداً بعناصر Play/Watch/Live الآمنة فقط؛ لا توجد نقرات عشوائية أو محاولات للتظاهر بسلوك بشري أو تجاوز أنظمة anti-bot.
- الاحتفاظ بالصفحة الأصلية وعدم السماح لنافذة جديدة بسرقة جلسة التشغيل.
- استمرار اكتشاف Player frameworks والمصادر العامة وfallback Native/WebView الموجود مسبقاً.

## ملاحظة مهمة

لا يوجد هنا تجاوز لـDRM أو authentication أو paywall أو CAPTCHA. الحماية تستهدف popups/redirects المزعجة والمحافظة على جلسة المشاهدة.

## التحقق

- تم فحص كتل JavaScript المضمنة في `watch_screen.dart` باستخدام Node syntax check.
- Flutter/Dart SDK غير متوفر في بيئة العمل الحالية، لذلك لم يتم تنفيذ `flutter analyze` أو APK build محلياً.
- يجب تشغيل Codemagic كاختبار البناء النهائي قبل رفع الإصدار.
